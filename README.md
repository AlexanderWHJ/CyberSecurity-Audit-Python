# CyberSecurity-Audit-Python
Sistema automatizado para el registro de incidentes, triage de seguridad y gestión de bases de datos JSON.
# 🛡️ Sistema de Gestión de Incidentes - AlexanderWHJ

## 📝 Descripción
Herramienta de ciberseguridad desarrollada en Python para automatizar la auditoría de ataques. El sistema permite registrar incidentes, asignar IDs dinámicos y generar reportes críticos inmediatos.

## ✨ Funcionalidades Clave
* **Registro Dinámico:** Manejo de persistencia en archivos JSON.
* **Triage Automatizado:** Filtrado de incidentes de gravedad "alta" y "crítica" mediante *List Comprehensions*.
* **Interfaz de Consola:** Reporte visual formateado para una rápida lectura del analista.

## 🚀 Cómo usarlo
1. Ejecuta el script `main.py`.
2. Introduce los datos del ataque (IP, puerto, gravedad).
3. Revisa el archivo `URGENTE_REVISAR.json` para el reporte de incidentes críticos.
